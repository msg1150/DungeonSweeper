# 던전별 시야·어둠 설정

플레이어 주변을 어둡게 만드는 시야 마스크를 `DungeonDefinition`별로 설정한다. 같은 던전의 모든 층에 적용하며, 기존 Easy·Normal·Hard 던전에는 변경 전 값인 **3 / 5 / 0.9**를 저장해 외관을 유지한다.

## 편집 위치

- **던전 제작 툴**: `Dungeon Sweeper → Dungeon Builder`에서 던전을 선택하고 **시야·어둠 (던전 전체)**를 수정한다. **저장 + 게임에 등록**으로 저장한다.
- **자동 생성**: 조건 입력 화면의 같은 설정을 수정한다. 도면을 다시 생성하지 않고도 바꿀 수 있고, 재생성 시 입력값을 유지한다. 후보를 채택하면 던전 에셋에 함께 저장한다.
- **던전 리소스**: `Assets/Resources/Dungeons`의 던전 에셋을 선택하고 Inspector의 **시야·어둠 (던전 전체)**를 수정한 뒤 Unity에서 에셋을 저장한다.

| 설정 | 초기값 | 의미 |
| --- | --- | --- |
| 선명 시야 반경 | 3 | 플레이어 주변에서 시야 마스크의 어둠을 적용하지 않는 월드 거리 |
| 바깥 어둠 반경 | 5 | 선명 반경부터 점차 어두워져, 이 거리에서 지정한 바깥 강도에 도달 |
| 바깥 어둠 강도 | 0.9 | 바깥 반경 이후의 검정 마스크 강도. 0은 마스크 없음, 1은 완전한 검정 |

예를 들어 밝은 던전은 **4 / 8 / 0.4**, 어두운 던전은 **2 / 4 / 0.95**처럼 조절한다. 반경은 양수이고 바깥 반경은 선명 반경보다 커야 하며 강도는 0~1의 유한한 값이어야 한다. 잘못된 값은 던전 검증 오류로 표시하고 등록·입장·빌드 검증에 반영한다.

## 기본값과 적용 시점

새 던전의 초기값은 `Assets/Resources/DungeonTuning.asset`의 **New Dungeon Vision Defaults**에서 복사한다. 기존 던전은 독립된 값을 가지므로 초기값을 바꿔도 따라 바뀌지 않는다. 특정 던전의 **현재 기본값 가져오기** 버튼을 누르면 현재 초기값을 그 던전에 복사한다.

실행 중 연결된 던전 에셋의 값을 수정하면 다음 표시 갱신부터 적용한다. 수동 도면 편집은 기존 툴 정책대로 Play 중 잠긴다. 이어하기도 저장된 Dungeon Id로 찾은 에셋의 현재 표시 설정을 사용하며 세이브 형식은 변경하지 않는다. 던전 정의나 시야 데이터가 없는 이전 실행 경로는 기존 DungeonTuning 값으로 표시한다.

이 설정은 화면의 시야 마스크를 조절한다. 몬스터 인식·청취 거리, 미니맵 탐색 기록의 발견 반경, 월드 조명은 별도로 유지한다. 기존 오버레이 한 장을 계속 사용하며 렌더러나 재질을 던전 설정 수만큼 추가하지 않는다.

## 수동 확인

1. EasyDungeon을 **4 / 8 / 0.4**, HardDungeon을 **2 / 4 / 0.95**로 설정하고 각 던전에 입장해 주변 시야와 바깥 어둠이 다른지 확인한다.
2. 같은 던전에서 층을 이동해 동일한 설정이 이어지는지 확인한다.
3. 저장 후 이어하기에서도 해당 던전의 설정을 사용하는지 확인한다.
4. 강도를 0으로 바꾸면 시야 마스크가 사라지고, 다시 값을 올리면 돌아오는지 확인한다.

## 에디터 검사

2026-10-21 격리 프로젝트에서 `Tools/Validate-GameFlow.ps1 -EditorOnly`로 기존 검사 포함 **134개**가 통과했다. 컴파일 오류·경고와 검사 예외는 없었다. 새 검사는 기본값 복사, 잘못된 값 거부, 2D/2.5D 셰이더 인자, 연결된 던전의 값 변경, 이전 경로의 기본값 호환, 수동·자동 생성과 후보 채택 시 값 저장 및 독립 복사를 확인한다. Play 모드·게임 실행은 수행하지 않았다.
