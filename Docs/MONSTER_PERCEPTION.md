# 몬스터 인식 범위 확인

## 플레이 중 상태 표시

몬스터가 플레이어를 발견해 추격하는 동안 머리 위에 **빨간 느낌표(!)**가 표시됩니다. 시야나 인식 범위에서 플레이어를 놓치고 마지막 목격 지점으로 이동하는 동안에는 **노란 물음표(?)**로 바뀝니다. 다시 발견하면 느낌표로 돌아가고, 목격 지점 추적이 끝나거나 은신에 성공하면 사라집니다. 플레이어를 발견한 적 없이 소음만 조사하는 상태에서는 표시하지 않습니다.

범위 디버그 체크와 무관하게 실제 게임 빌드에서도 표시합니다. 캐릭터 머리의 불투명 영역을 기준으로 위치를 잡아 공격 프레임의 여백에 따라 흔들리지 않으며, 카메라를 향한 표시는 던전의 벽·어둠 합성 안에서 그립니다. 두 종류의 도형과 재질은 공유하고, 개체별 표시는 풀 반환 시 숨긴 뒤 재사용합니다.

직접 확인할 때는 몬스터에게 접근해 느낌표를 확인하고, 인식 원 밖이나 벽 뒤로 이동해 물음표로 바뀌는지 확인하세요. 다시 나타나면 느낌표가 돌아오고, 은신하거나 탐색을 마치면 표시가 없어져야 합니다.

## 에디터 표시

1. Project 창에서 `Assets/Resources/DungeonTuning.asset`을 선택합니다.
2. Inspector의 **Editor Debug → Show Monster Perception Ranges**를 체크합니다.
3. 플레이하고 던전에 입장하면 **Game 뷰**에 원과 몬스터별 반경 수치가 표시됩니다. 플레이 중 체크를 해제하면 즉시 사라집니다.

단축키는 사용하지 않습니다. 기본값은 꺼짐이며, 표시 컴포넌트와 체크박스는 `UNITY_EDITOR` 조건 안에 있어 게임 빌드에는 포함되지 않습니다. 체크 상태는 에디터의 튜닝 에셋 설정으로 유지됩니다. 표시가 꺼져 있으면 원 투영과 문자열 생성도 수행하지 않습니다.

| 표시 | 의미 |
| --- | --- |
| 노란 실선 | 몬스터 중심의 기본 플레이어 인식 반경 |
| 하늘색 점선 | 몬스터 중심의 소음 청취 반경. 해체 실패 지점이 이 안에 있어야 반응 |
| 빨간 실선 | 소음을 들은 후 현재 실제 판정에 사용하는 확장 인식 반경. 경계 중에만 표시 |
| 보라색 실선 | 숨는 순간 은신을 발각하는 거리. 원 위·안에서는 숨기 실패 |
| 몬스터 옆 수치 | 현재 인식 반경 / 기본 반경 / 청취 반경, 남은 경계 시간 |

원은 월드 거리 기준의 원을 현재 카메라에 투영합니다. 2.5D에서는 바닥 위의 타원처럼 보입니다. 어둠과 벽에 가리지 않고 그리는 디버그 표시이며, 실제 시야 판정에서는 **기본·확장 상태 모두 벽에 가린 플레이어를 발견하지 못합니다**. 표시와 추적 판정은 같은 `CurrentDetectionRange` 값을 사용합니다.

범위 선은 모든 몬스터를 공유 UI 메시로 묶어 그립니다. 몬스터 4마리의 선분이 한 Graphic에 들어가며 색·점선·확장 원을 유지합니다. 텍스트는 기존 HUD에 표시하고, 비활성 상태에는 투영과 메시 갱신을 생략합니다. 실제 Draw Calls 비교 방법은 [그리기 요청 최적화 기록](RENDERING_OPTIMIZATION_2026-10-21.md)을 참고하세요.

## 몬스터별 설정

`Assets/Prefabs/Monsters/`의 몬스터 프리팹을 선택하고 **Monster Prefab → Stats**를 펼칩니다.

| 필드 | 용도 | 기존 세 종류의 기본값 |
| --- | --- | --- |
| Detection Range | 평상시 플레이어 발견 반경 | 3.8 |
| Hearing Range | 해체 실패 소음을 듣는 반경 | 8 |
| Hiding Reveal Range | 은신 시도를 발각하는 반경. 숨는 순간 거리로 판정하며 벽·소음 배율과 무관 | 2 |
| Noise Detection Multiplier | 소음을 들은 뒤 기본 인식 반경에 곱하는 배율 | 2 |
| Noise Alert Seconds | 인식 반경 확대 유지 시간 | 6초 |
| Investigation Seconds | 소리 위치에 도착한 뒤 조사 시간. 추적 중에도 감소 | 6초 |

예를 들어 기본 반경 3.8, 배율 2인 몬스터는 소음을 들으면 6초 동안 **7.6** 반경에서 플레이어를 발견합니다. 배율은 1보다 크게 설정합니다. 청취 반경과 확장 시야는 독립된 설정입니다. 소음은 청취 거리로 판단하고 시야처럼 벽으로 차단하지 않습니다.

매 해체 실패는 기존 소음 전달 경로를 통해 해당 위치가 청취 반경 안에 있는 몬스터만 경계시킵니다. 소음을 다시 들으면 확대 배율을 중첩하지 않고 지속 시간을 새로 갱신합니다. 범위 밖의 몬스터는 변하지 않습니다. 프리팹 설정은 생성 시 복사하므로 **변경한 값은 새로 생성하는 몬스터부터 적용**됩니다. 저장에서 복원한 몬스터는 저장 당시 능력치를 사용합니다.

경계 시간은 이동·조사·추적·공격 중 감소하고, 일시정지와 비활성 층에서는 멈춥니다. 시간이 끝나면 인식 반경은 즉시 기본값으로 돌아갑니다. 소리 위치 조사 시간은 기존 동작을 유지하므로 반경 확대가 끝나도 조사 이동이 이어질 수 있습니다.

## 시야를 잃은 뒤의 추적

몬스터는 인식 반경 안이고 벽에 가리지 않은 플레이어 위치를 기억합니다. 반경을 벗어나거나 벽 뒤로 숨으면 즉시 순찰로 돌아가지 않고 **마지막 목격 지점까지 추격 속도로 이동**합니다. 이동 중 플레이어를 다시 발견하면 현재 위치를 추격하고 기억도 갱신합니다. 보이지 않는 동안에는 실제 플레이어 위치로 목표를 갱신하거나 공격을 새로 시작하지 않습니다.

마지막 목격 지점에 도착해도 다시 발견하지 못하면 순찰을 재개합니다. 남아 있는 소음 조사가 있으면 이를 먼저 처리하며, 시야를 잃기 전에 시작한 공격은 기존 타격 거리·벽 차단 판정에 따라 마무리합니다. 목격 지점까지 유효한 경로가 없으면 추적을 중단해 멈춰 서 있는 상태를 방지합니다. 소음으로 확장된 인식 반경이 만료돼도 마지막 목격 지점까지 이동하는 기억은 유지됩니다.

기억한 위치와 유효 여부는 저장·층 이동 시 보존하고 풀 반환 시 초기화합니다. 기존 저장은 목격 기록이 없는 상태로 호환됩니다.

몸체 크기의 직선 이동 검사를 통과하는 구간은 대각선으로 바로 접근합니다. 벽이 있으면 통로 경로를 사용하되, 안전하게 생략할 수 있는 중간 칸은 건너뜁니다. 목적지가 같은 칸 안에서 조금 움직여도 완료한 경로를 출발 칸 중심부터 다시 밟지 않습니다.

은신처에서는 예외로, 숨기에 성공하면 공격·추격·목격 기록·기존 소음 조사가 즉시 끊깁니다. 같은 층의 몬스터 중 하나라도 `Hiding Reveal Range` 이내에 있으면 숨기가 실패하고 해당 몬스터가 시도 위치를 알아챕니다. 성공 후에는 E로 나올 때까지 인식되지 않습니다. [은신처 배치·테스트 안내](DUNGEON_BUILDER.md#은신처-배치와-사용)를 참고하세요.

## 검증

- 빈 방에서 몬스터와 대각선으로 서고 천천히 좌우로 움직입니다. 몬스터가 칸 중심으로 되돌아가며 떨지 않고 거리를 좁히는지 확인합니다. 좁은 통로·벽 모서리에서는 벽을 가로지르지 않고 우회하는지도 확인합니다.

- 해체 실패 후 청취 범위 안의 몬스터에 빨간 원이 나타나고 현재 반경이 증가하는지 확인합니다.
- 기본 원 바깥·빨간 원 안에 벽 없이 서면 추적하고, 벽 뒤에 있으면 발견하지 못하는지 확인합니다.
- 실패를 반복하면 남은 시간이 갱신되되 원이 계속 커지지는 않는지 확인합니다.
- 시간이 끝나면 빨간 원이 사라지고 현재 반경이 기본 반경으로 돌아오는지 확인합니다.
- 경계 상태에서 저장·로드하거나 층을 왕복하면 남은 경계 시간이 복원됩니다. 반환된 풀 개체는 다음 스폰에 경계 상태를 넘기지 않습니다.
- 몬스터에게 발견된 뒤 인식 원 밖으로 달아나거나 벽 뒤로 숨습니다. 즉시 순찰하지 않고 마지막으로 보였던 위치까지 오는지 확인합니다.
- 그 상태로 다른 곳으로 이동해 몬스터가 보이지 않는 현재 위치까지 따라오지는 않는지 확인합니다. 다시 인식 범위 안에 나타나면 추격이 재개되어야 합니다.
- 마지막 목격 지점으로 이동 중 저장·로드하거나 층을 왕복해도 추적 목표가 유지되는지 확인합니다.

자동 검증은 `Tests/DungeonPopulationChecks.cs`의 `RunPerception` 및 `Tests/DungeonPoolChecks.cs`에 포함되어 있습니다. `Tools/Validate-GameFlow.ps1 -CaptureScreens`로 에디터와 그래픽을 사용하는 Windows 빌드 검증을 함께 실행합니다.
