# 던전·층별 보상 테이블

같은 시체 프리팹의 기본 전리품 목록을 재사용하면서 던전·층마다 드롭 확률과 수량만 변경합니다. 전리품의 이름·가격 범위·가방 형태와 시체의 해체 난이도는 기존 프리팹 설정을 사용합니다. 테이블을 연결하지 않으면 기존 확률과 성공 시 1개 드롭을 유지합니다.

## 제작 순서

1. Project 창에서 **Create → Dungeon Sweeper → Loot Reward Table**로 에셋을 만듭니다. Resources 폴더에 둘 필요는 없습니다.
2. Inspector 아래의 **시체 프리팹 추가**에 프리팹을 넣습니다. 해당 시체의 모든 기본 전리품이 한 묶음으로 표시됩니다. 같은 프리팹은 여러 번 넣어도 중복 등록되지 않습니다.
3. 변경할 전리품의 **개별 설정**을 켜고 **드롭 확률 (%)**, **최소 수량**, **최대 수량**을 입력합니다. **모두 개별 설정 / 모두 상속** 버튼으로 그 시체의 전체 전리품을 한 번에 전환할 수도 있습니다. 새 개별 설정은 시체 프리팹의 기본 확률과 수량 1개로 시작하며 기존 개별 설정값은 유지합니다.
4. 던전 제작 창 또는 던전 Inspector의 **기본 보상 테이블 (선택)**에 연결합니다.
5. 특정 층만 다르게 설정하려면 해당 층의 **이 층의 보상 테이블 (선택)**에 별도 테이블을 연결합니다.
6. 제작 창에서는 **저장 + 게임에 등록**으로 저장합니다. 자동 생성 미리보기에서도 **이 층의 스폰·보상 설정**을 열어 연결한 뒤 채택할 수 있습니다. Inspector에서 직접 편집했다면 Unity에서 에셋을 저장하세요.

연결된 필드 아래의 **보상 테이블 편집** 버튼으로 해당 에셋을 선택할 수 있습니다. 테이블 하나를 여러 던전이나 층에서 공유해도 됩니다.

시체별 제목 왼쪽 화살표로 묶음을 접을 수 있습니다. **시체 제거**는 그 테이블의 시체 묶음과 개별 보상 설정만 제거하며 프리팹 에셋이나 던전 스폰 수를 변경하지 않습니다. 편집과 제거는 Unity의 Undo/Redo를 지원합니다.

프리팹에 전리품을 추가하면 테이블 목록에도 자동으로 표시되고, 개별 설정을 켜기 전까지 상속을 사용합니다. 기본 목록에서 제거한 전리품의 기존 개별 설정은 오류로 표시하므로 **이 잘못된 설정 삭제**로 정리하세요. 이전 방식으로 만든 테이블도 기존 확률·수량을 보존한 채 시체별로 묶어서 표시합니다.

## 적용 규칙

각 **시체 프리팹 + 전리품 ID** 조합마다 다음 순서로 값을 찾습니다.

1. 해당 층의 테이블에서 **개별 설정**을 켰으면 그 값을 사용합니다.
2. 껐으면 던전 기본 테이블의 개별 설정을 사용합니다.
3. 둘 다 없으면 시체 프리팹의 기본 확률과 수량 1개를 사용합니다.

층 테이블에 시체를 등록해도 개별 설정을 끈 전리품은 던전 테이블을 상속합니다. 특정 항목을 제외하려면 개별 설정을 켜고 확률을 **0%**로 지정합니다. 개별 설정을 끄면 그 항목의 덮어쓰기 값을 제거하고 다시 상속합니다. 모든 항목을 상속하는 시체 묶음도 화면에 유지됩니다. 상속 안내에 표시하는 시체 기본 확률은 참고값이며 실제 적용값은 상위 테이블 설정에 따라 달라집니다.

예를 들어 던전 기본 테이블에 고블린 이빨 80%·1~2개, 고블린 가죽 60%·1개를 지정하고 2층 테이블에는 고블린 가죽 90%·2개만 넣으면 다음과 같습니다.

| 항목 | 1층 | 2층 |
| --- | --- | --- |
| 고블린 이빨 | 80%, 1~2개 | 80%, 1~2개 |
| 고블린 가죽 | 60%, 1개 | 90%, 2개 |
| 그 외 기본 전리품 | 프리팹 기본값 | 프리팹 기본값 |

각 항목은 **독립적으로 한 번** 추첨합니다. 확률 합계는 100%일 필요가 없으며, 추첨에 성공한 항목만 최소~최대 수량을 양 끝값 포함해 뽑습니다. 수량만큼 개별 전리품을 생성하므로 각각 가방 공간을 사용하고, 가격도 프리팹의 기존 가격 범위에서 개별 결정됩니다.

수량은 1~32개이며 시체 하나의 최대 가능 드롭 수 합계는 256개입니다. 테이블은 최대 1024개의 개별 설정을 허용합니다. 상속 항목은 이 한도를 사용하지 않습니다. 프리팹에 없는 전리품, 같은 조합의 중복 설정, 누락된 프리팹, 잘못된 확률·수량은 검증 오류로 표시합니다. 새 종류 추가와 가격 변경은 시체 프리팹에서 진행하세요. 출시 준비의 가방 확장 재료 획득 가능성 검사도 층·던전의 유효 보상 설정을 반영합니다.

## 저장과 적용 시점

새 탐험을 시작할 때 **미방문 층을 포함한 모든 층**의 유효 보상 규칙과 기본 전리품 값을 복사합니다. 실제 전리품 추첨은 각 층의 시체를 처음 생성할 때 한 번 수행합니다. 저장하거나 층을 왕복하거나 이어하기를 해도 확정된 전리품을 다시 추첨하지 않습니다.

테이블이나 프리팹을 수정해도 진행 중인 새 형식 탐험의 보상 규칙은 바뀌지 않습니다. 수정 내용은 다음 새 탐험부터 적용됩니다. 보상 규칙이 없는 이전 저장은 기존 기본 드롭 경로로 호환하며 새 테이블을 소급 적용하지 않습니다.

## 수동 플레이 확인

1. 기본 테이블에 특정 항목을 **100% / 최소 3 / 최대 3**으로 설정하고 새로 입장해 해당 시체를 회수합니다. 그 항목이 3개인지 확인합니다. 다른 항목은 기존 확률대로 함께 나올 수 있습니다.
2. 특정 층 테이블에 같은 항목을 **0%**로 설정합니다. 해당 층에서는 나오지 않고 다른 층에서는 기본 테이블의 3개 설정을 사용하는지 확인합니다.
3. 던전에서 저장 후 이어하기와 층 왕복을 해도 이미 결정된 전리품 종류·수량·가격이 유지되는지 확인합니다.
4. 탐험 도중 테이블을 수정해도 미방문 층의 규칙은 유지되고, 마을 귀환 후 새로 입장하면 수정값을 사용하는지 확인합니다.
5. 테이블에서 시체 프리팹을 한 번 넣었을 때 모든 전리품이 보이는지, 기존 설정이 유지되는지 확인합니다. 개별 설정 끄기·시체 제거 후 Ctrl+Z와 Ctrl+Y로 설정이 함께 복구·제거되는지도 확인합니다.

## 에디터 검사

2026-10-19에 격리 프로젝트에서 `Tools/Validate-GameFlow.ps1 -EditorOnly`를 실행해 기존 검사 포함 **96개**를 통과했습니다. C# 컴파일 오류·경고와 검사 예외는 없었습니다. Play 모드는 실행하지 않았습니다.

보상 검사는 기본값과 난수 소비 호환, 항목별 상속·0% 제외, 독립 추첨과 수량 범위, 잘못된 행 거부, 저장된 전리품의 재추첨 방지, 미방문 층 규칙의 JSON 저장·복원과 독립 복사, 자동 생성 채택 후 테이블 참조 유지, 확장 재료 획득 가능성 검사를 포함합니다. 시체별 묶음 편집에 대해서도 기존 설정 보존·중복 등록 방지·전체 설정 전환·새 기본 전리품 자동 표시·오래된 설정 정리·상속만 쓰는 묶음의 에셋 저장·재임포트·그룹 제거의 Undo/Redo를 확인했습니다.
