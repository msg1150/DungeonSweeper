# 던전·층별 보상 테이블

같은 시체 프리팹의 기본 전리품 목록을 재사용하면서 던전·층마다 드롭 확률과 수량만 변경합니다. 전리품의 이름·가격 범위·가방 형태와 시체의 해체 난이도는 기존 프리팹 설정을 사용합니다. 테이블을 연결하지 않으면 기존 확률과 성공 시 1개 드롭을 유지합니다.

## 제작 순서

1. Project 창에서 **Create → Dungeon Sweeper → Loot Reward Table**로 에셋을 만듭니다. Resources 폴더에 둘 필요는 없습니다.
2. Inspector의 **보상 항목 추가**를 누르고 **시체 프리팹**을 지정합니다.
3. **기본 전리품** 목록에서 변경할 항목을 선택한 뒤 **드롭 확률 (%)**, **최소 수량**, **최대 수량**을 입력합니다.
4. 던전 제작 창 또는 던전 Inspector의 **기본 보상 테이블 (선택)**에 연결합니다.
5. 특정 층만 다르게 설정하려면 해당 층의 **이 층의 보상 테이블 (선택)**에 별도 테이블을 연결합니다.
6. 제작 창에서는 **저장 + 게임에 등록**으로 저장합니다. 자동 생성 미리보기에서도 **이 층의 스폰·보상 설정**을 열어 연결한 뒤 채택할 수 있습니다. Inspector에서 직접 편집했다면 Unity에서 에셋을 저장하세요.

연결된 필드 아래의 **보상 테이블 편집** 버튼으로 해당 에셋을 선택할 수 있습니다. 테이블 하나를 여러 던전이나 층에서 공유해도 됩니다.

## 적용 규칙

각 **시체 프리팹 + 전리품 ID** 조합마다 다음 순서로 값을 찾습니다.

1. 해당 층의 테이블에 행이 있으면 그 값을 사용합니다.
2. 없으면 던전 기본 테이블의 행을 사용합니다.
3. 둘 다 없으면 시체 프리팹의 기본 확률과 수량 1개를 사용합니다.

층 테이블을 지정해도 그 안에 없는 항목은 던전 테이블을 상속합니다. 특정 항목을 제외하려면 해당 조합의 확률을 **0%**로 지정합니다. 빈 테이블은 모든 값을 상속합니다.

예를 들어 던전 기본 테이블에 고블린 이빨 80%·1~2개, 고블린 가죽 60%·1개를 지정하고 2층 테이블에는 고블린 가죽 90%·2개만 넣으면 다음과 같습니다.

| 항목 | 1층 | 2층 |
| --- | --- | --- |
| 고블린 이빨 | 80%, 1~2개 | 80%, 1~2개 |
| 고블린 가죽 | 60%, 1개 | 90%, 2개 |
| 그 외 기본 전리품 | 프리팹 기본값 | 프리팹 기본값 |

각 항목은 **독립적으로 한 번** 추첨합니다. 확률 합계는 100%일 필요가 없으며, 추첨에 성공한 항목만 최소~최대 수량을 양 끝값 포함해 뽑습니다. 수량만큼 개별 전리품을 생성하므로 각각 가방 공간을 사용하고, 가격도 프리팹의 기존 가격 범위에서 개별 결정됩니다.

수량은 1~32개이며 시체 하나의 최대 가능 드롭 수 합계는 256개입니다. 테이블은 최대 1024행을 허용합니다. 프리팹에 없는 전리품, 같은 조합의 중복 행, 누락된 프리팹, 잘못된 확률·수량은 검증 오류로 표시합니다. 새 종류 추가와 가격 변경은 시체 프리팹에서 진행하세요. 출시 준비의 가방 확장 재료 획득 가능성 검사도 층·던전의 유효 보상 설정을 반영합니다.

## 저장과 적용 시점

새 탐험을 시작할 때 **미방문 층을 포함한 모든 층**의 유효 보상 규칙과 기본 전리품 값을 복사합니다. 실제 전리품 추첨은 각 층의 시체를 처음 생성할 때 한 번 수행합니다. 저장하거나 층을 왕복하거나 이어하기를 해도 확정된 전리품을 다시 추첨하지 않습니다.

테이블이나 프리팹을 수정해도 진행 중인 새 형식 탐험의 보상 규칙은 바뀌지 않습니다. 수정 내용은 다음 새 탐험부터 적용됩니다. 보상 규칙이 없는 이전 저장은 기존 기본 드롭 경로로 호환하며 새 테이블을 소급 적용하지 않습니다.

## 수동 플레이 확인

1. 기본 테이블에 특정 항목을 **100% / 최소 3 / 최대 3**으로 설정하고 새로 입장해 해당 시체를 회수합니다. 그 항목이 3개인지 확인합니다. 다른 항목은 기존 확률대로 함께 나올 수 있습니다.
2. 특정 층 테이블에 같은 항목을 **0%**로 설정합니다. 해당 층에서는 나오지 않고 다른 층에서는 기본 테이블의 3개 설정을 사용하는지 확인합니다.
3. 던전에서 저장 후 이어하기와 층 왕복을 해도 이미 결정된 전리품 종류·수량·가격이 유지되는지 확인합니다.
4. 탐험 도중 테이블을 수정해도 미방문 층의 규칙은 유지되고, 마을 귀환 후 새로 입장하면 수정값을 사용하는지 확인합니다.
