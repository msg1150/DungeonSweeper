# 메뉴 이미지 에셋

`Assets/Art/MainMenu/UI/`는 제공된 `DungeonSweeper_MainMenu_UI_v1`의 개별 PNG 23개를 원본 그대로 복사한 폴더입니다. 합성 시안인 `previews`는 게임 배경으로 사용하지 않습니다. 로고는 기존 `Assets/Art/MainMenu/DungeonSweeperLogo.png`를 계속 사용합니다.

## 화면별 연결

| 이미지 | 사용하는 기능 |
| --- | --- |
| `backgrounds/background_main.png` | 메인 화면 배경 |
| `panels/panel_menu.png` | 메인 메뉴와 일시정지 메뉴 |
| `panels/panel_options.png` | 옵션창과 저장·불러오기 슬롯창 |
| `panels/panel_dialog.png` | 저장 덮어쓰기 확인과 알림 |
| `buttons/labeled` | 제공된 원본 보관용. 현재 UI에는 연결하지 않음 |
| `buttons/skins` | 모든 버튼의 기본·강조·누름·비활성 배경. 글씨는 공통 텍스트 레이어로 표시 |
| `controls/slider_*` | 전체 음량·음악·효과음의 바탕·채움·손잡이 |
| `controls/toggle_*` | 전체화면 / 창 모드 전환 |
| `controls/checkbox_*` | 수직 동기화 켜짐 / 꺼짐 |
| `icons/button_close.png` | 옵션창 닫기: 적용하지 않은 변경을 버리고 돌아가기 |
| `icons/button_back.png` | 저장·불러오기 슬롯창에서 돌아가기 |

시안에 있는 화면 흔들림 항목은 현재 게임 설정에 없는 기능이므로 추가하지 않았습니다. 해상도·그래픽 품질·프레임 제한과 기본값 복원은 기존 기능을 유지합니다. 옵션은 **적용**을 눌렀을 때 저장되고, 닫기·돌아가기·Esc는 적용하지 않은 변경을 버립니다.

## 이미지 교체와 조절

- `Assets/Resources/MainMenuPresentation.asset`의 **Background Image**, **Logo**, **Menu Ui**에서 에셋을 연결합니다. **Menu Panel Opacity / Menu Button Opacity**는 메인 화면 패널·버튼 투명도입니다.
- `Assets/Resources/MenuUiArt.asset`에서 각 역할의 이미지와 **Uv**를 교체합니다. Uv는 투명 여백을 제외한 그림 영역이며 좌측 하단을 원점으로 하는 0~1 좌표입니다. 원본 이미지 전체를 사용하려면 `(0, 0, 1, 1)`로 지정합니다.
- UV는 Inspector에서 편집해 Unity의 Rect 저장 형식을 유지합니다. `serializedVersion: 2`가 빠진 수동 YAML은 표시 영역을 0으로 읽게 할 수 있습니다. 필수 패널·버튼 원화를 읽을 수 없으면 글자색과 버튼도 함께 기본 테마로 돌아갑니다.
- 메뉴 전용 렌더러가 패널을 9개 영역으로, 글자 없는 버튼을 가로 3개 영역으로 나눠 그립니다. 큰 창이나 긴 저장 슬롯에서 모서리가 과하게 늘어나지 않게 하며, 렌더링 중 텍스처를 생성하거나 PNG 픽셀을 수정하지 않습니다.
- 입력·슬라이더 드래그는 Unity 기본 IMGUI 컨트롤을 사용합니다. 다른 월드 HUD와 거래소의 밝은 테마는 기존 `GameUiTheme`를 사용합니다.
- UI 텍스처는 투명도 사용, Mipmap 끄기, Read/Write 끄기, Clamp 설정입니다. 배경 최대 크기는 2048, 패널·버튼·슬라이더 바는 1024, 스위치는 512, 아이콘·체크박스·손잡이는 256입니다.

## 확인 범위와 수동 확인

2026-10-22: 격리된 프로젝트에서 `Tools/Validate-GameFlow.ps1 -EditorOnly`로 컴파일 및 에디터 검사 167개를 통과했습니다. 기존 검사에 실제 Unity 역직렬화 이후의 메뉴 원화 16개의 텍스처·UV 검사와 잘못된 UV의 기본 테마 전환 조건을 추가했습니다. 수정 전에는 메뉴 패널 UV가 0으로 읽히는 실패를 재현했고, Unity 자체 직렬화로 저장한 뒤 유효한 영역이 복원되는 것을 확인했습니다. 복사한 PNG 23개의 SHA-256은 제공된 원본과 같습니다. Play 모드와 실제 화면·입력 검사는 실행하지 않았습니다.

1. `MainMenu` 씬에서 실행해 배경, 로고, 버튼 4개의 배치를 확인합니다. 제목 아래 설명은 표시하지 않습니다.
2. 버튼에 마우스를 올리거나 눌러도 글꼴·크기·위치가 그대로인지 확인합니다. 메인 버튼은 28 크기의 굵은 글씨를 공통으로 사용합니다. 누른 채 바깥으로 이동한 뒤 놓으면 실행되지 않아야 합니다.
3. 이어하기에서 비어 있는 슬롯은 선택되지 않는지, 저장 데이터가 있는 슬롯은 불러올 수 있는지 확인합니다. 뒤로 화살표로 돌아옵니다.
4. 옵션에서 슬라이더를 끝까지 드래그하고 전체화면·수직 동기화를 전환합니다. 적용 후 다시 열면 값이 유지되고, 적용 없이 닫으면 변경이 버려지는지 확인합니다.
5. 마을·던전에서 Esc 메뉴를 열어 메뉴 이미지, 저장 슬롯과 덮어쓰기 확인창의 글자가 읽히는지 확인합니다.
